# Data dictionary

| Dataset | ID | Link | Licence | What we use | Real / SYNTHETIC |
|---|---|---|---|---|---|
| NASA Open Science Data Repository, Inspiration4 blood study | OSD-569 (file LSDS-7, Complete Blood Count) | https://osdr.nasa.gov/bio/repo/data/studies/OSD-569 | NASA open data (CC0 unless marked); cited | Complete blood count for four crew at three pre-launch and four post-return timepoints, with laboratory reference ranges. The within-person variation of the pre-launch haemoglobin draws sets the width of the haemoglobin band, and the haemoglobin laboratory ranges set its limit. All four blood counts are drawn on the "Real crew data" screen | Real |
| NASA DONKI, solar energetic particle (SEP) events | DONKI SEP | https://ccmc.gsfc.nasa.gov/tools/DONKI/ | NASA public data; cited | Solar particle events bundled at build time. Events that fall inside the mission window set the days that carry a radiation prompt, and the latest event is shown on the space-weather card | Real |
| NASA technical standard, cabin carbon dioxide limit | NASA-STD-3001 Volume 2 | none held in the repo | NASA published standard; cited | One number: the one-hour average cabin carbon dioxide limit of 3 mmHg. It is a habitat design requirement, not a clinical alert threshold | Real |
| Simulated mission, four crew (`src/data/seed.json`) | none | made by the team with `scripts/make_mission_data.py` (fixed seed 2026) | Apache 2.0 | Six indicators for four crew members: a pre-flight baseline (14 days; 3 draws for haemoglobin; the first two mission weeks for cabin carbon dioxide) and 86 mission days, with day 87 as today. Also the fixed configuration: indicator explanation cards, five environment profiles, the crew timeline, the privacy table | SYNTHETIC values; real haemoglobin variation and ranges, real carbon dioxide limit, real radiation prompt days |

Notes: the app's six indicators are sleep (h), resting heart rate (bpm), mood (1 to 5), reaction time (ms), cabin carbon dioxide (mmHg) and haemoglobin (g/dL). Cabin carbon dioxide comes from a cabin sensor in a real system; in the demo it is SYNTHETIC and no sensor is connected. The other three blood counts (haematocrit, red cells, white cells) appear only on the "Real crew data" screen. OSD-569 has no in-flight draws. Timepoints are L-92, L-44, L-3 (days before launch) and R+1, R+45, R+82, R+194 (days after return). To change the simulated data, edit `scripts/make_mission_data.py` and run it again; do not edit `seed.json` by hand.
