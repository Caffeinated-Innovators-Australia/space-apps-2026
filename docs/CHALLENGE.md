# Challenge: Create Health Monitoring Software for Astronauts on Space Missions

NASA Space Apps Challenge 2026. Official page: https://www.spaceappschallenge.org/2026/challenges/health-monitoring-software/

The verbatim statement is on the official page. This file holds our traceability table: each row is one thing the statement asks for.

## Traceability table

| Row | The statement asks for | Type |
|---|---|---|
| R1 | Software that gathers health indicators | Objective |
| R2 | Enables astronauts to evaluate their own health status | Objective |
| R3 | Enables astronauts to act on it, with guidance on treatments and health improvements | Objective |
| R4 | A visual tool for self-assessment by the astronaut | Objective |
| R5 | Data that represents a health indicator, with units | Objective |
| Q1 | Which measurements can be performed in space? | Guiding question |
| Q2 | Why is an exam needed? | Guiding question |
| Q3 | How do spaceflight hazards affect these health indicators? | Guiding question |
| Q4 | When might a result warrant attention from the crew or from flight surgeons on the ground? | Guiding question |
| Q5 | What actions can be taken to prevent a critical health condition? | Guiding question |
| U1 | Present metrics and assessment clearly; interface design matters | Interface |
| C1 | Consider a clickable human figure | Consideration |
| C2 | Consider different environments: spacecraft, station, rover, base | Consideration |
| C3 | Consider prompting measurements as part of the mission routine | Consideration |
| C4 | Consider gamification, dynamic charts and colour coding | Consideration |
| C5 | Consider simple instructions, because astronauts are not assumed to be medical experts | Consideration |
| C6 | Consider any input: keyboard, mouse clicks or camera images | Consideration |
