# Challenge: Create Health Monitoring Software for Astronauts on Space Missions

NASA Space Apps Challenge 2026. Official page: https://www.spaceappschallenge.org/2026/challenges/health-monitoring-software/

The verbatim statement is on the official page. This file holds our traceability table: each row is one thing the statement asks for.

## Traceability table

| Row | The statement asks for | Type | Where in the product |
|---|---|---|---|
| R1 | Software that gathers health indicators | Objective | Reading screen (typed or tapped value); "Feeling off?" one-tap log on home |
| R2 | Enables astronauts to evaluate their own health status | Objective | Result screen: chart against own baseline, tier pill |
| R3 | Enables astronauts to act on it, with guidance on treatments and health improvements | Objective | Result screen: numbered steps; gap screen: "meanwhile" tick list and case pack |
| R4 | A visual tool for self-assessment by the astronaut | Objective | Whole app: astronaut-facing, body figure home |
| R5 | Data that represents a health indicator, with units | Objective | Unit on every value; real NASA data on "Real crew data" and space-weather card |
| Q1 | Which measurements can be performed in space? | Guiding question | Reading screen: "How is it measured in flight?" (awaiting clinician wording) |
| Q2 | Why is an exam needed? | Guiding question | Reading screen: "Why this check?" (awaiting clinician wording) |
| Q3 | How do spaceflight hazards affect these health indicators? | Guiding question | Reading screen: links to NASA HRP hazards and risks; home: space-weather card |
| Q4 | When might a result warrant attention from the crew or from flight surgeons on the ground? | Guiding question | Result screen: three tiers; gap screen: when Earth can reply |
| Q5 | What actions can be taken to prevent a critical health condition? | Guiding question | Result screen: numbered steps for every tier |
| U1 | Present metrics and assessment clearly; interface design matters | Interface | Tier as colour, shape and word; "Why this alert?" with source and confidence |
| C1 | Consider a clickable human figure | Consideration | Home: tappable body figure (one region live in the demo) |
| C2 | Consider different environments: spacecraft, station, rover, base | Consideration | "Where are you?" selector: Moon, Mars closest, Mars farthest, remote Australia |
| C3 | Consider prompting measurements as part of the mission routine | Consideration | Home: space-weather prompt from NASA DONKI |
| C4 | Consider gamification, dynamic charts and colour coding | Consideration | Chart with baseline band; colour coding with shape and word. Gamification: not addressed |
| C5 | Consider simple instructions, because astronauts are not assumed to be medical experts | Consideration | Plain-language why lines and steps throughout |
| C6 | Consider any input: keyboard, mouse clicks or camera images | Consideration | Keyboard and tap input. Camera: not addressed |
